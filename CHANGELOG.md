# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0-mvp] - 2026-02-23
### Added
- Core framework-agnostic evaluation runtime.
- JSONL suite loading and row-level validation.
- Assertion system with text, regex, JSON schema, semantic, and function-calling assertions.
- CLI binary `vendor/bin/php-evals` with table/json output and CI exit codes.
- Console and JSON reporting paths.
- Laravel bridge with service provider and `ai:eval` Artisan command.
- Test suite coverage for core and Laravel bridge.
- Documentation for quickstart, assertions, function-calling, CI, installation, and extension.
- Release checklist and hardened QA workflow.
